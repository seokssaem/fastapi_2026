# 전국 축제 데이터 기반 지자체 축제 기획 및 의사결정 지원 시스템

> **전국 문화축제 데이터를 바탕으로 지자체 공무원 및 기획자가 축제 인프라(행사 기간, 대중교통 접근성, 온라인 홍보 등)에 따른 효과를 과학적으로 검토하고 기획 성공 가능성을 극대화할 수 있는 Web 기반 의사결정 지원 플랫폼입니다.**

---

## 스트림릿 웹 애플리케이션 주요 UI 구성 및 기능

사용자 인터페이스는 최신 Streamlit 문법(`st.Page` 및 `st.navigation`)을 통해 왼쪽 사이드바 메뉴판으로 독립 제어됩니다.

### 1. 메인 (Main Area)
- **방문객 수 예측 페이지 (`streamlit_app.py`)**
  - 기획 중인 축제의 `행사기간`, `버스정류장수`, `지하철유무`, `SNS 및 홈페이지 유무`를 입력받아 백엔드에서 학습된 파이프라인 모델을 실시간 로드하여 예상 유입 규모를 예측 시뮬레이션합니다.

### 2. 데이터 탐색 (Data Exploration Area)
- **전국 문화축제 행사 빠른검색 페이지**
  - 원본 축제 데이터 셋에서 키워드(축제명, 장소)를 기반으로 실제 전국 성공 사례를 1초 만에 필터링 조회합니다.
  - 검색된 축제들의 평균 행사기간을 동적으로 연산하여 기획 가이드 팁을 실시간 제공합니다.
- **전국 문화축제 행사 상세검색 페이지**
  - 다각도의 세부 필터링 조건을 결합하여 타 지자체의 성공적인 축제 네이밍 및 최적의 개최 장소 인프라를 정밀 벤치마킹합니다.

### 3. 기타 (Insight Area)
- **기간 및 대중교통 인프라 추이 페이지**
  - 행사 기간의 볼륨 및 주변 교통환경이 관람객 유치에 미치는 거시적 추이와 인사이트 통계 분석 리포트를 시각적으로 제공합니다.

## 백엔드 머신러닝 파이프라인 아키텍처 (`13_test.pipelien.py`)

웹 화면 구동과 철저히 분리되어 백엔드(메모리 상)에서 데이터 가공 및 모델 성능 평가를 수행하는 청정 파이프라인입니다.

1. **명시적 특성 분리 및 전처리 (`ColumnTransformer`)**
   - **입력 특성(X):** `행사기간`, `버스정류장수` (수치형) / `홈페이지주소`, `지하철유무` (범주형)
   - **숫자형 특성 처리 파이프라인:** `SimpleImputer(median)` 결측치 대체 ➔ `StandardScaler()` 표준화 스케일링
   - **범주형 특성 처리 파이프라인:** `SimpleImputer(most_frequent)` 결측치 대체 ➔ `OneHotEncoder()` 벡터 변환
2. **임계치 기준 최종 분류 및 평가 (`RandomForestClassifier`)**
   - 예측 확률이 **0.5 이상이면 기획 이탈(1)**, **0.5 미만이면 비이탈(0)**로 분류하는 임계치 매핑 적용.
   - `confusion_matrix`, `accuracy`, `roc_auc_score` 분석 지표를 완벽 연산합니다.
3. **핵심 자료 파일 자동 저장 (하단 폴더 바로 아래 생성)**
   - **`festival_pipeline_model.joblib`**: 전처리 공정과 모델이 결합된 통합 파이프라인 세이브 파일.
   - **`pipeline_metrics.json`**: 사람이 읽을 수 있는 형태로 `ensure_ascii=False`, `indent=2` 규격을 적용해 한글 깨짐 없이 기록한 요약 보고서 파일.

##  프로젝트 시작 가이드 (How to Run)

1. **필수 라이브러리 원클릭 설치**
   ```bash
   pip install pandas scikit-learn streamlit joblib
   ```
2. **독립형 백엔드 파이프라인 가동 (모델 및 JSON 보고서 추출)**
   ```bash
   python 13_test.pipelien.py
   ```
3. **통합 다중 페이지 스트림릿 서비스 구동**
   ```bash
   streamlit run main.py
   ```
